I had the idea of developing a program with a graphical user interface to demonstrate how a sorting algorithm works and to illustrate its efficiency.

Since I am currently learning Java, I thought this language would be well suited for the project. It would allow me both to strengthen my fundamentals and to learn new concepts.

The first challenge I encountered was deciding how to organize the project architecture. I therefore chose to create three packages, as it is important to structure the code properly, even for a small project.
